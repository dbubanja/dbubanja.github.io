# Затезна камата ЦГ

PWA апликација за обрачун законске затезне камате по прописима Црне Горе, намијењена судским вјештацима економско‑финансијске струке. Ради на Android‑у, Windows‑у и macOS‑у, у прегледачу или инсталирана, и **без интернета** након прве инсталације. Подаци о предметима остају искључиво на уређају (IndexedDB). Апликација нема налоге, аналитику ни рекламе.

> Статус: функционална верзија 1.0.0 спремна за пробу. Видјети [ИЗВЈЕШТАЈ_О_ПРОВЈЕРАМА.md](ИЗВЈЕШТАЈ_О_ПРОВЈЕРАМА.md): шта је тестирано, а шта још чека вашу провјеру.

---

## 1. Објављивање на GitHub Pages (једном)

**Важно за Android APK:** датотека `assetlinks.json` мора бити на корену домена (`https://…/.well-known/assetlinks.json`). Зато изаберите **једну** од ове двије адресе:

- **А) Репозиторијум назван `КОРИСНИЧКО-ИМЕ.github.io`** — апликација је на `https://КОРИСНИЧКО-ИМЕ.github.io/`. Ово је најједноставније и препоручено.
- **Б) Сопствени поддомен**, нпр. `kamata.vasdomen.me` — у корен репозиторијума додајте фајл `CNAME` са тим именом, а код регистра домена CNAME запис ка `КОРИСНИЧКО-ИМЕ.github.io`.

(Обичан репозиторијум `…github.io/kamata/` ради за инсталацију из прегледача, али **не** за APK без траке са адресом.)

Кораци:
1. На github.com: **New repository** → назив по варијанти А → *Public* → **Create**.
2. **Add file → Upload files** → превуците САДРЖАЈ ове фасцикле (не саму фасциклу), укључујући фасцикле `.github` и `.well-known`. Ако их прегледач сакрије, отпремите их посебно или користите GitHub Desktop.
3. **Settings → Pages → Source: GitHub Actions**.
4. **Settings → Actions → General → Workflow permissions:** *Read and write* + укључите *Allow GitHub Actions to create and approve pull requests* (потребно за провјеру стопа).
5. **Actions** картица: сачекајте да „Тестови и објава на GitHub Pages“ буде зелено (тестови механизма се покрећу прије сваке објаве; ако падну, апликација се не објављује).

## 2. Инсталирање

**Android (Chrome):** отворите адресу → мени ⋮ → **Инсталирај апликацију** / *Додај на почетни екран*. При дну апликације сачекајте ознаку **„Спремно за офлајн рад“**.

**Windows / macOS (Chrome или Edge):** отворите адресу → икона за инсталацију у траци адресе (⊕) или мени → *Инсталирај Затезна камата ЦГ*. Покреће се као засебан прозор, са истим могућностима као на телефону.

**iPhone (Safari):** Подијели → *Додај на почетни екран* (ради, али није посебно тестирано).

**Телефон и рачунар имају одвојене податке.** Пренос: *Копија → Извези све* на једном уређају, *Увези фајл* на другом. Аутоматске синхронизације нема.

## 3. Ажурирање стопа (полугођа од 1.1. и 1.7.)

ЦБЦГ нема сервис са којег апликација може директно да чита стопе, а прегледач не смије да чита сајт ЦБЦГ (CORS ограничење; дугме *Стопе → Пробај директан приступ ЦБЦГ* то провјерава на вашем уређају). Зато ажурирање иде овако:

1. **Аутоматски приједлог.** Од 1. до 20. јануара и јула GitHub Actions („Провјера нових стопа ЦБЦГ“) свакодневно провјерава страницу ЦБЦГ. Ако нађе нову одлуку, прочита стопу, период и број из **садржаја** одлуке и отвори *pull request* са ставком у статусу **„непотврђено“**. Можете га покренути и ручно: *Actions → Провјера нових стопа ЦБЦГ → Run workflow*.
2. **Ваша провјера.** Отворите изворну одлуку из PR‑а и провјерите стопу, период, број и датум одлуке (а не број акта о овлашћењу потписника из преамбуле). Затим у `rates.json` за ту ставку:
   - поставите `"статус": "потврђено"`;
   - попуните `датум_одлуке`, `службени_лист` и `провјерено_дана`;
   - повећајте `"version"`.
3. **Спајање (Merge pull request).** Апликација се објављује аутоматски.
4. **На уређајима:** *Стопе → Провјери ажурирање стопа* приказује разлике и тражи потврду. Претходна верзија табеле остаје сачувана, а сачувани обрачуни се не мијењају.

Ручна алтернатива: измијените `rates.json` директно на GitHub‑у (оловка ✎) по истом обрасцу.

Без интернета: *Стопе → Учитај rates.json из фајла*.

Ако аутоматска провјера не нађе одлуку или не може да прочита скенирани документ, то пише у извјештају. Постојећа табела се у том случају не мијења.

## 4. Android APK преко PWABuilder‑а

1. Апликација мора бити објављена (варијанта А или Б из одјељка 1).
2. Отворите **https://www.pwabuilder.com** → унесите адресу апликације → **Package for stores → Android → Generate**.
3. У опцијама:
   - *Package ID*, нпр. `me.vjestak.zateznakamata`, који касније не мијењате;
   - *App name*: „Затезна камата ЦГ“;
   - *Signing key*: **New** (PWABuilder прави кључ).
4. Преузмите ZIP. Он садржи:
   - `.apk` за дијељење колегама;
   - `.aab` за Google Play (ако икад затреба);
   - **`signing.keystore` и `signing-key-info.txt`** са лозинкама;
   - `assetlinks.json`.
5. **Кључ чувајте трајно** (`signing.keystore` + лозинке), на два мјеста ван рачунара. Без њега колеге не могу да ажурирају APK, него морају да деинсталирају стару верзију и изгубе локалне податке. Прије тога нека направе извоз.
6. Садржај добијеног `assetlinks.json` (назив пакета и SHA‑256 отисак) копирајте у `.well-known/assetlinks.json` у репозиторијуму и сачекајте објаву. Тек тада APK ради без траке са адресом.
7. Колеге инсталирају `.apk`: отворе фајл на телефону и дозволе *инсталирање из непознатих извора* за апликацију из које отварају фајл (нпр. Viber, Gmail, Фајлови).

**Ажурирања апликације** не захтијевају нови APK. APK отвара објављену адресу, па свака нова објава на GitHub‑у стиже свима. У апликацији се појави трака **„Доступна је нова верзија — Освјежи“**, а нова верзија се не активира сама усред рада.

## 5. Структура

```
index.html, css/app.css            интерфејс
js/engine.js                       обрачунски механизам (чиста функција)
js/rational.js                     тачна рационална аритметика (BigInt)
js/dates.js, js/parse.js           календарски датуми и тумачење уноса
js/xlsx-export.js                  Excel са формулама (ExcelJS, lib/exceljs.min.js локално)
js/app.js, storage.js, rates.js    апликација, IndexedDB, табеле стопа
sw.js, manifest.webmanifest, icons офлајн рад и инсталација
rates.json, Pregled_stopa_CBCG.html  законске стопе ЦБЦГ 2010–2026 са изворима
tests/                             тестови (видјети извјештај о провјерама)
tools/check_cbcg.py                провјера нових одлука ЦБЦГ (GitHub Actions)
.github/workflows/                 објава + провјера стопа
.well-known/assetlinks.json        шаблон за APK (попунити)
```

## 6. Тестови (за одржавање)

```
npm install
npm test                                      # референтни прорачун дан‑по‑дан + 40 тестова механизма
node tests/xlsx-build.mjs && python3 tests/xlsx_verify.py   # Excel формуле у LibreOffice, поређење на цент
python3 tests/e2e.py                          # цијели ток у Chromium‑у (Playwright), укључујући офлајн
```
