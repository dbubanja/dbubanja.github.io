# Извјештај о провјерама — Камата Студио 2.0.1

Датум: 02.11.2026. Ово је списак стварно извршених провјера, не потврда подобности за конкретан судски предмет.

## Извршено локално

- 63 Node теста: сви прошли. Међу њима 27 сценарија упоређених са независним Python Fraction прорачуном дан по дан. Поређени су тачни разломци, а не само приказ на цент.
- Обухват: пријеступна година, прелаз године и стопе, оба правила граничних дана, исти/обрнути датум, дјелимична камата, гашење главнице, преплата, више главница, намјена/сразмјерно/доспијеће, исти дан, два третмана уплате, нулта и ручна стопа, празнина/преклапање, комбиноване стопе, мале и велике вриједности, трошкови код „само на главницу“.
- Три теста service worker-а симулирају одсутну мрежу: сви наведени ресурси постоје и учитавају се из кеша, стара апликација и онлајн провјера стопа се не пресрећу, стари туђи кеш се не брише, skipWaiting тражи изричиту поруку.
- У прегледачу провјерено чување током уноса, Enter навигација, одбијање двосмисленог износа и исправка уноса.
- SHA-256 отисак детектује измјену снимка. Провјерено одбијање неисправне структуре резервне копије и небезбједне адресе извора. Измјене основа и хеша видљиве у поређењу стопа.
- Бројач: филтрира само одговарајуће APK фајлове, сабира GitHub download_count, грешка мреже/ограничење API-ја није нула.
- ExcelJS направио 44 XLSX датотеке (22 важећа сценарија × 2 писма). Сценарио са главницом преко сигурног Excel опсега је изричито прескочен; сам тачни прорачун је тестиран.
- Скрипта ЦБЦГ је приступила живој страници; нема нових одлука у односу на уграђене 34 ставке. Није било нове одлуке на којој би се потврдио цијели будући поступак OCR → PR.
- У прегледачу тестирани прикази 360 и 390 px преко iframe оквира: нема хоризонталног преливања странице. Ово није тест физичког телефона.
- Визуелно прегледани почетни екран, илустративни обрачун и дијалог реда у Chrome-у. Примјер: 1.000 € од 31.12.2023. до 31.12.2024, уплата 100 € на 30.06.2024: камата 121,41 €, преостали дуг 1.021,41 €.

## Провјере које треба разликовати од извршених

- Локално није био доступан LibreOffice; инсталација у овом окружењу није успјела. Накнадно је GitHub Actions успјешно извршио LibreOffice прерачун свих 44 XLSX датотека: ниједан извјештај није имао разлику на цент. [Извршење 41509168063](https://github.com/dbubanja/dbubanja.github.io/actions/runs/41509168063).
- Локални преглед користи HTTP, па не може доказати PWA инсталацију или service worker. На објављеној HTTPS адреси провјерени су регистрација service worker-а (приказ „Спремно за офлајн рад“), чување снимка са отиском и стварно преузимање Excel-а. Физичко искључивање мреже није извршено у облачном прегледачу.
- Нијесу извршени физички Android/iPhone/macOS тестови, потписивање и инсталација APK-а, ни стварни прелаз са старије на новију PWA верзију.
- Провјерени примјер из стварног предмета није достављен. Није извршено поређење са тим налазом.

За пуштање у судску употребу: контролни налаз на цент, провјера примјењивих прописа и правила, прерачун Excel-а, пробни JSON извоз/увоз и провјера резервне копије на другом уређају.

## Бројач на објављеној адреси

GitHub бројач је приказао 0 APK датотека и 0 преузимања, у складу са празном Releases листом. Приступ јавном GoatCounter бројачу није успио; интерфејс приказује недоступност. Број PWA инсталација није потврђен. Није генерисан лажни тестни догађај инсталације.
